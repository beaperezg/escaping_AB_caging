# Escaping Aharonov–Bohm caging

Code to reproduce the figures of

> A. Ahmed, M. Benito and B. Pérez-González, *Escaping AB caging via Floquet engineering: drive-induced long-range
> interference in an all-band-flat model*, [arXiv:2511.20255](https://arxiv.org/abs/2511.20255)

The model is a π-flux diamond (rhombic) chain whose on-site energies are driven by a square wave. The code computes its
exact Floquet spectrum and stroboscopic dynamics, the high-frequency effective Hamiltonian and its mapping to a
decorated SSH chain, Zak phases, and the dynamics and entanglement of two interacting fermions.

The numerical data is not included in this repository. All of it can be computed with the notebooks provided here
(see [How to run](#how-to-run)).

## Structure

```
paper_reproduction/
├── pyproject.toml         dependencies (managed with uv)
├── uv.lock                exact versions of all packages
├── .python-version        Python version used by uv (3.13)
├── Source/                Python modules used by the notebooks
├── Notebooks/
│   ├── Results for manuscript/   one notebook per figure: computes the data and saves it to Data/
│   └── Create Figures/           Plot_all_figures.ipynb: reads Data/ and makes all figures
├── Data/                  computed data (.npz), one or more files per figure (not included, created when the
│                          notebooks are run)
└── Figures/
    ├── Figures for paper/        figures of the main text and the Appendix
    └── Schematics/               hand-drawn schematics (Figs. 1, 3 and 4 d)), not generated by code
```

Notebooks and data files are named after the figure they belong to: `FigXX_*` for Fig. XX of the main text and
`FigAXX_*` for Fig. AXX of the Appendix. `FigA02_A08_zak_phase` computes the data of both Figs. A2 and A8.

### Source

The modules are installed in the environment as top-level modules, so they are imported as `import diamond_chain`,
`import two_particles`, etc.

| Module | Content |
|---|---|
| `diamond_chain.py` | single-particle chain: Bloch Hamiltonian, finite chain, drive, exact square-wave Floquet operator, stroboscopic evolution and site occupations. The module docstring defines the conventions used everywhere else. |
| `effective_model.py` | high-frequency effective model: Γ, renormalized hoppings J0, J1, J2, H_eff(k), diamond chain with long-range hoppings, SSH chain |
| `two_particles.py` | interacting fermions: Fock basis, Hamiltonian, time evolution, partitions, entanglement measures, two-particle Floquet spectrum |
| `zak_phase.py` | Zak phases (discrete Wilson loop) of the exact Floquet bands and of H_eff(k) |
| `sort_bands_algorithm.py` | follows bands through crossings by comparing eigenvectors |
| `line_gradient_colors.py` | lines colored by a third quantity (plotting) |
| `parallel_utils.py` | parameter sweeps with joblib or MPI |
| `data_io.py` | saves and loads `.npz` files together with their parameters (stored as JSON) |
| `paper_style.mplstyle` | matplotlib style of the figures |

## Conventions

- Bloch basis (C, U, D); the flux φ sits on the C–D bond.
- Finite chains have sites ordered {C₁, U₁, D₁, C₂, …}. A *closed* chain ends with the extra site C_{N+1} (3N + 1
  sites), an *open* chain does not (3N sites). Cells are counted from 1.
- Drive: f(t) = +A for the first half-period and −A for the second, on U and, with factor `zeta`, on D (`zeta = +1`
  symmetric, `zeta = -1` antisymmetric driving).
- The drive is piecewise constant, so the one-period propagator is computed exactly as
  U(T) = exp(−iH₋T/2) exp(−iH₊T/2). Only Figs. A9 and A10 use QuTiP's ODE solver (`sesolve`).

## Installation

Dependencies are managed with [uv](https://docs.astral.sh/uv/). From this folder:

```bash
uv sync
```

This installs Python 3.13 and the package versions pinned in `uv.lock` (NumPy, SciPy, Matplotlib, QuTiP, joblib, tqdm
and JupyterLab), and installs the modules in `Source/` in editable mode.

By default uv creates the environment in `.venv/` inside this folder. If the folder is in a synced location (OneDrive,
Dropbox, …), you can keep the environment elsewhere by setting `UV_PROJECT_ENVIRONMENT` before running uv, e.g.

```bash
export UV_PROJECT_ENVIRONMENT="$HOME/.venvs/paper_reproduction"
```

The variable has to be set in every new shell (or added to your shell profile).

The figures are typeset with LaTeX (`text.usetex: True` in `paper_style.mplstyle`), so plotting needs a LaTeX
installation.

## How to run

Notebooks find `Data/` and `Figures/` relative to the current directory, so **run each one from its own folder**. To
work interactively:

```bash
uv run jupyter lab
```

To run a notebook from the terminal:

```bash
cd "Notebooks/Results for manuscript"
uv run jupyter nbconvert --to notebook --execute --inplace Fig04_dynamics_from_C_site.ipynb
```

Steps to reproduce all figures:

1. **Compute the data.** Run the notebooks in `Notebooks/Results for manuscript/` (in any order). Each one writes its
   data file to `Data/`, which is created if it does not exist.
2. **Make the figures.** Run `Notebooks/Create Figures/Plot_all_figures.ipynb`. It only reads `Data/` and saves the
   figures to `Figures/Figures for paper/`, with the file names used in the LaTeX source.

The data is not distributed with the code, so step 1 has to be run before step 2.

Running times: `FigA09_fourier_transform_entanglement` and `FigA10_max_entanglement_vs_A_and_V` take about 20 and 15
minutes with 11 cores (they run in parallel with joblib). All other notebooks run in about a minute in total.
